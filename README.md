# kapi
KERI API

KERI API documentation, tooling and testing.

- [kapi.md](kapi.md): the original KAPI design essay (2024).
- [routes.md](routes.md): the route principle, tiers, conventions and open questions.
- [registry.md](registry.md): every route keripy serves or sends, generated by [scripts/getroutes.py](scripts/getroutes.py) from keripy source and [routes.toml](routes.toml).
- [docs/api-spec.yaml](docs/api-spec.yaml): an OpenAPI description of KERIA's REST endpoints as of May 2024.
